# WP6 — production upper-body gestures

20 October 2026. WP6 only, awaiting owner review. **`MIGHTY_GESTURES_V2` remains off by default.** Gesture intent uses the existing tagged sentence metadata (`MIGHTY_STREAM_CHAT` for generated tags). The body consumer works independently of `MIGHTY_EXPR_V2`; GLB faces remain unsupported. No WP7 latency work or flag-default changes.

## Implementation

`Shared/GestureRules.cjs` supplies the 12 production tags, clip pools, nonrepeating selection, pace calculation and upper-body mask to AnimationLab and production. AnimationLab retains its extra experimental actions and manual controls. Production uses `0.7 + 0.6*pace` with at most ±0.03 variation, rotates talking takes without immediate repeats and allows at most one non-talking launch per eight monotonic seconds. Cooldown survives new turns in the same controller.

`GestureController` consumes the existing phase/performance/playback messages in the renderer's frame pass. Positive playback progress triggers the current sentence's intent. Text or ready audio alone cannot launch a gesture. Later sentence boundaries use the existing Edge word alignment; audio-only or old metadata without alignment does not invent later timestamps. A clock jump across several boundaries selects the current sentence once, avoiding skipped zero-duration takes and accidental visible repeats. Carried sentence indices do not execute twice across phrase chunks. Generation/utterance/sequence fences reject stale output.

The controller has one live take and at most one frozen outgoing pose during a short crossfade. New input/cancel/error freezes the outgoing action clock and fades its weight over approximately 0.18 seconds. Non-thinking actions cannot advance during the thinking phase; the same bounded release can still be visible. An explicit `thinking` take may advance during a playback pause. Audio completion releases the action. Pausing motion freezes the take clock; cancellation can still fade it back to the paused base.

Production does not animate AnimationLab's mannequin directly. `export-production-gestures.mjs` samples its actual `tagged-character.glb` into the retargeter's existing absolute-rest-delta format, with source hashes. Fifteen source takes implement the 12 tags (three talking, two arguing, ten single-clip tags). The optional JSON is about 9.6 MiB, shipped as a separate asset and fetched only with gestures enabled. Export verification checks it against the current source GLB. No new runtime library is needed.

`IdleMotion` retains its existing Japanese, English, Mixamo and Bip001 binder/calibration. It samples gesture poses through that same solver, then blends calibrated **local rotations** under the shared mask: Spine 0.25, Spine1 0.6, upper chest/head/arms/hands 1. Hip/root translations and the full leg chain remain the selected idle's output. Gesture root motion is not applied. The base clock, style transitions, ground-contact handling and pointer attention continue normally. Face head/gaze offsets run afterwards on the fresh gesture result; no rotations accumulate.

Gestures require head, a spine binding, and both arm/forearm/hand chains. Insufficient rigs skip gestures and keep rendering/idle. Missing optional clip data also leaves the character usable. Native and typed phase/identity/cue forwarding is enabled by either the gesture flag or the face flag, so gestures do not secretly depend on the new face engine. Existing call v2 and renderer speech v1 remain unchanged.

- [MMD grid](wp6-evidence/mmd-grid.png), [GLB grid](wp6-evidence/glb-grid.png), individual full-take WebM recordings and [rendering receipt](wp6-evidence/rendering.json) cover all 12 tags on actual Aalto MMD and Hailey GLB. Both grids were visually inspected. The MMD run includes expressive-face output; the GLB run keeps `MIGHTY_EXPR_V2` off. These use controlled phase/playback snapshots, not provider speech or a physical input-to-pixel measurement. Each tag starts in an independent session; cooldown behavior is checked separately. Representative frames are chosen from source motion rather than just the first second, since some authored clips start slowly.
- The rendered checks reject gestures before positive playback, check finite bound output, verify flag-off views do not fetch gesture data, and include a visible frozen-clock cancellation fade. Coalesced cues select one current nonrepeated take. The original source timing is retained: long takes can be cut short by real audio ending, so a very short utterance may finish before a slow gesture's strongest pose. No automatic clip trimming or naturalness improvement is claimed.
- [GLB paired retarget check](wp6-evidence/retarget.json) and [MMD paired retarget check](wp6-evidence/retarget-mmd.json) run all 12 full takes under all three selected idle styles, **16,653 frames per rig**, alongside identical-clock gesture-free baselines. Maximum hip/leg/foot local and world transform difference is **0** on both rigs. Quaternions remain normalized and finite. The actual 367-bone MMD runtime is exercised with its usual disabled physics. A further 120-frame actual-GLB probe checks additive face head offsets on the gesture pose without accumulation.
- Controller checks cover cooldown (including the eight-second boundary), pace, no immediate talking repeats, word boundaries, missing rigs, cancellation, thinking restrictions, stale input and coalesced cues. The typed bridge also checks gesture-only flags and pace/identity preservation.
- [Native enabled receipt](wp6-evidence/gesture-native.json) and [disabled receipt](wp6-evidence/gesture-native-off.json) exercise actual local hold/commit, fixture STT/reply/audio, real decode/sample-clock playback and sentence metadata with the face flag off. Output is muted; no real provider or physical microphone quality claim is made.
- Existing AnimationLab's 26-clip check passes male/female stance preservation, thinking-to-reply transitions, varied talking, recovery and bounded active clips. Existing idle checks pass 30-second motion/seam/foot checks, rapid style switching, gaze direction, and actual Jean MMD pointer behavior. Related face/coverage, speech-energy, streaming, player speech, memory UI, timing, provider, phrase, protocol, native reducer/coordinator and authenticated network/audio checks pass. Coverage remains 40/46.
- Renderer TypeScript, isolated production build and full native source typecheck pass, with existing dependency/deprecation warnings. Generated source bundles and the installed app were not replaced. The unrelated pre-WP1 portrait-count failure remains documented.

Recorded grids and clips establish the inspected rigs' behavior, not equal gesture quality on every character. Static clothing and model proportions can still affect clearance; no collision solver or all-model visual calibration is added here. No blind human preference or latency improvement is claimed.

## Reproduce

From the workspace root, run `bash 'Mighty Chat/scripts/test-production-gestures.sh'`. The MMD paired check needs the already prepared Aalto model in the existing character cache. `model-viewer-clean/tools/export-production-gestures.mjs` rebuilds the optional clip asset; `--check` verifies it without changing it.

Run `bash 'Mighty Chat/scripts/test-production-gestures-native.sh'` with ordinary macOS local networking/audio access. For rendered checks, build the isolated bundle with `node model-viewer-clean/node_modules/webpack-cli/bin/cli.js --config 'Mighty Chat/Renderer/webpack.config.cjs' --output-path /private/tmp/mighty-wp6-renderer`, then run `Mighty Chat/tests/animation/check-gesture-rendering.cjs` with Playwright on `NODE_PATH`. Full captures take several minutes; run GPU checks serially. The isolated server stage has no credential agent, and its synthetic native fixture credentials cannot modify saved configuration.

Source, bundle and evidence hashes are in `wp6-evidence/manifest.json`. [Spec deviations](SPEC-DEVIATIONS.md) record the code-informed decisions. Stop before WP7.
