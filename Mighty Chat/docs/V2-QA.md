## Failures investigated, not discarded

1. The editor's assertion counted every portrait with a URL, including an already completed local image. It now asserts three unresolved images, preserving the connection-limit test, and starts its own private server instead of assuming port 8765.
2. Desktop pause/resume sends pointer controls as well as hover controls. The old test waited for exactly three total messages and for the last message to be hover reset. It now checks the hover sequence independently and still asserts reset when the character changes.
3. Current production uses `SelectedIdleLoop`, with no endpoint hold; the rendering test waited for an unreachable old sequence state. It now explicitly selects the male loop and freezes a finite moving pose. The new `release` capture mode validates current lighting, transparency, framing and motion without a historical image comparison; the existing comparison mode still requires its baseline and retains its comparisons. No lighting improvement is claimed.
4. Initial native synthetic turns sometimes lost the second visible phrase/start stamp. An isolated PCM check measured actual audio-route changes during startup and reversed completion callbacks when buffers were interrupted. Production intentionally cancels on route changes. Fixtures now allow three seconds before synthetic input, and native audio suites run serially. The new primitive check waits for two seconds of quiet route state and still fails on a route change during the buffers. All original failure/diagnostic logs remain. No production cancellation behavior or latency limit was weakened; cold-start/route-switch performance is not established by these tests.

The disposable copy initially excluded nested directories named `build`, including six vendored JavaScript/type files. The copy filter now excludes only the app's top-level output directory. Restored files match source, the candidate was re-signed, and signed-memory packaging was rerun. This was a test staging correction, not an application code change.

In that snapshot run `bash scripts/build.sh` to build the isolated candidate, then run the original workspace's `tests/release/run-candidate-checks.py`.
