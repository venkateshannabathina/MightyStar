# Pocket TTS integration

Mode: Improve. Scope: use the approved Pocket Alba voice for app speech, retaining Edge and OpenAI as selectable engines. Preserve the chat/orb presentation, generation ordering, cancellation, playback clock, and sentence text. No random fillers or cached Edge openings in Pocket replies.

Performance contract: physical MacBook Air M2, 8 GB, macOS 27.0.1, optimized native app plus official arm64 Pocket binary from v4.0.1 release (archive labelled 3.3.0). Startup/model copy measured separately from model-resident synthesis; synthesis first PCM is not first audible speaker output or total STT/LLM/reply latency. Warm model between utterances; no API key required by Pocket.

Provider: persistent localhost process with packaged English weights and Alba voice state. A writable temporary model cache is seeded from packaged resources on first use, avoiding writes inside the signed bundle. Warmup runs when the voice session starts. Process closes with backend, abort disconnect cancels active HTTP generation, stale jobs cannot write completed audio. Restart on subsequent request after process failure. Speech worker receives only runtime/cache environment variables, no provider API keys.

Current transport prepares complete sentence audio before native playback; it does not yet feed Pocket PCM frames directly to the audio device. Native first playback therefore includes sentence generation, download and decode, rather than matching the model’s first-PCM metric. Local provider smoke test: startup including initial cache seed 1596 ms; two short replies first PCM 79/46 ms and fully prepared audio 312/391 ms. These are two observations, not a latency percentile or matched Edge comparison. Earlier isolated trial data: build/pocket-tts-trial/results.json.

Pocket outputs 24 kHz mono PCM WAV. Provider repairs the streaming header’s placeholder lengths; the existing UUID audio route serves the WAV with its correct MIME type. Native decoder chooses WAV or MP3 based on container signature. The native queue still uses actual PCM clocks and trims external silence. Model provides no word alignment: preserve sentence captions and energy-based mouth movement, emit no fabricated word timestamps. Natural speed only for this Pocket integration; speed/pitch controls disabled for Pocket. Retain Edge voice settings for switching back.

Validation: provider checks cover audio validation, actual duration, header lengths, errors and cancellation during model startup/generation. Full native fixture uses synthetic transcript/LLM text with real Pocket synthesis, real local transport/audio route, AVAudioFile decoding and muted sample clock; checks two coherent sentences, displayed/spoken agreement, completion, no Edge openings and no fabricated word timing. No user microphone recording or saved conversations are used in tests. Existing staged build/regressions passed, with existing compiler deprecation warnings only.
