# Character Facial Key Library

[Open the searchable visual library](index.html)

50 cached PMX/BPMX model variants; 4,789 controls; 19,206 captures.

Each reference contains neutral, 25%, 50%, 100%, and three-quarter-at-100% views. Pose and automatic face motion were frozen. The original Jean reference is retained; remaining references use actual renderer-pixel JPEG captures at quality 94%.

**Limitations:** One legacy Nicole model has gray substitute materials because its original source path/textures could not be recovered. It is a geometry-only study, not a finished textured face reference. Other galleries flag unavailable referenced textures. Undownloaded catalog models and GLB characters are excluded. The production app and facial engine were not changed.
